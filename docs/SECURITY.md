# 脅威モデル

## 前提

このプロダクトは、**信頼できない外部サイトのテキストを LLM に読ませ、その出力でブラウザを操作します。**

プロンプトインジェクションは想定上のリスクではなく、業務上の前提条件です。
「サイトの本文を読んで次に押すリンクを決める」という動作は、
そのページに書かれた任意の文字列を、判断の入力として受け取ることと同じです。

私たちは観測パイプラインを自前で持っています。
つまり **LLM に渡る前に検査できる位置にいます。** ここは設計上の偶然ではなく、選択です。

```
ページ → observe() → 【脅威検査】 → constrain() → LLM
                          ↑
              ここを通らないバイトは LLM に届かない
```

## 想定する脅威

| 種別 | 内容 | 想定される実害 |
|---|---|---|
| `prompt_injection` | ページ本文・alt 属性・非表示要素に埋め込まれた指示文 | エージェントの乗っ取り。外部サイトへの誘導、意図しない操作 |
| `pii` | 観測したページに含まれる個人情報 | 顧客の機密が上流モデルへ送られる |
| `tool_abuse` | 許可していない道具の呼び出し | 読み取り専用の原則の破壊 |
| `offsite_navigation` | 対象ドメイン外への遷移 | 権限のないサイトへのアクセス |

## 記録する — 握りつぶさない

検出結果は `ThreatRecord` としてトレースに残り、画面に表示されます。

```ts
type ThreatRecord = {
  kind; severity; location; excerpt;
  verdict:  "allow" | "review" | "block";
  detector: "local" | "orcarouter_firewall" | "orcarouter_pii";
  note_ja;
}
```

黙って弾くと、**「防いだ」という事実の証拠が残りません。**
何を検出し、どう判定し、なぜその判定にしたかを、原文の抜粋つきで保存します。

`excerpt` には問題になった文字列をそのまま入れます。
インシデント後に「何が来ていたのか」を人が読めなければ、防御の検証ができません。

## 二層構成

| 層 | 担当 |
|---|---|
| **ローカル検査**（`security/`） | 観測直後。パターン検査と、対象ドメイン外への遷移の拒否 |
| **OrcaRouter 側** | PII Shield（上流呼び出しと課金の前に判定）／ Agent Firewall（ツール・MCP 呼び出しの事前評価） |

PII Shield によるブロックは HTTP 400 で返ります。
クライアントはこれを**通信エラーとして飲み込みません** — 正常な防御動作なので、そのまま記録します。

```ts
// llm/orca.ts
if (res.status < 500) throw new OrcaError(res.status, raw);
// 4xx は再試行しない。PII Shield のブロックもここに来るが、それは正常系である
```

## 検証方法

インジェクションの検証は、**ローカルのフィクスチャに対してのみ**行います。

`fixtures/` にハニーポットページを置き、そこに指示文を埋め込みます。
**他者のサイトには一切設置しません。** 実在の自治体サイトや企業サイトを検証台にはしません。

検証で見るのは 2 点です。

1. 検出されること（`ThreatRecord` が記録されること）
2. **エージェントが指示に従わないこと** — 検出だけでは防御になりません

## 秘密情報の取り扱い

- `.env` はコミットしません。`.env.example` にキー名だけを置きます。
- ワークツリーごとに `.env` をコピーします（gitignore 対象なので自動では引き継がれません）。
- Supabase の RLS は、`anon` を **読み取り専用**にしています。書き込みはランナーの service role のみです。

## 対象サイトに対して行わないこと

境界は「ログインまたは申請があるかどうか」です。そこから先が法的な線です。

- 会員登録・ログイン・マイナンバー認証
- フォーム送信
- 電子申請システム（ぴったりサービス、Graffer、LoGo フォーム 等）への進入
- robots.txt に反するアクセス、同一ドメインへの並列アクセス
