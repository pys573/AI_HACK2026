# デモ動画 字幕台本（撮影・編集用）

> **これは字幕そのもの。** 考え方・なぜその言い方をするのかは `video-script.md` にある。
> あちらを消さない — 質疑で効くのは向こうの注記の方だ。
>
> 目標尺 **2分50秒**（3分を超えると失格）。絶対規則7 によりすべて事前録画。
> 数字は `web/public/demo/matrix.json`（`batchv2` 世代・有効125ラン）と一致している。
> **画面の横棒は対照群を除いた「制約側の離脱率」**（`SiteBars.tsx:33`）。ここを混ぜない。

## 字幕の書き方

- 1行 **20文字以内**、最大2行。日本語字幕は **1秒あたり4文字**で読める。
- 数字を出す字幕には、同じ画面に **プロファイルID + version** か **n** を置く。
  離れた瞬間に「検証できない主張」になる。
- 「サイト監査」「アクセシビリティ検査」は使わない。

## D｜1:25–2:05　結果 — サイトが割れる

**画面** `/report` のサイト別横棒。**いちばん低い棒といちばん高い棒が並ぶ1枚。**
その下に点グラフ（点1個＝実行1回）。

| in | out | 字幕 |
|---|---|---|
| 1:25 | 1:30 | 同じ用事で5つの自治体を回しました |
| 1:30 | 1:35 | 制約なしなら、どのサイトでも着きます |
| 1:35 | 1:41 | 制約をかけると、割れました |
| 1:41 | 1:48 | 渋谷区では**20回に1回も止まらない**<br>港区では**20回中19回が止まる** |
| 1:48 | 1:53 | 違うのは**サイトだけ**です |
| 1:53 | 1:59 | 港区も、制約なしなら4回中4回とも到達。<br>通れない場所ではありません |
| 1:59 | 2:05 | つまり「AIができない」のではなく<br>**サイトを測った値**です |

**画面テロップ（常時）**
```
同じ用事（転入届）・同じ制約・違うのはサイトだけ
渋谷区 離脱 4%  ↔  港区 離脱 95%   ※対照群を除いた制約側
n＝125（制約プロファイル実行結果 / batchv2）
```

> ⚠️ **画面の横棒は「離脱率」。** 到達率で喋ると画面と裏返しになって一瞬で分からなくなる。
> **離脱側に揃えた**のが上の字幕。到達で言いたいときは必ず「到達」の2文字を付ける
> （渋谷区 23/24 到達＝96% ↔ 港区 1/20 到達＝5%、どちらも制約側）。

### ★ 弱点を出す（2:05–2:14）— **尺が足りなくても削らない**

| in | out | 字幕 |
|---|---|---|
| 2:05 | 2:10 | 対照群も100%ではありません。**21/23** |
| 2:10 | 2:14 | 25マス中**9マス**は結果が揺れています。<br>マス単位では断定しません |

> 落ちた2件はどちらも渋谷区。1件は「転居届」との取り違え、
> もう1件は一覧までは着いたが持ち物が載っていなかった方だ。**言い換えるときも混ぜない。**
> 隠したと取られる方が高くつく（`video-script.md` の注記）。
