# persona/ — カード上部の写真について

## これは何か

| ファイル | 表示名 |
|---|---|
| `senior-70s.jpg` | 高齢者 |
| `resident-n3.jpg` | 外国人住民 |
| `smartphone-novice.jpg` | デジタル初心者 |
| `busy-worker.jpg` | 時間がない人 |

チーム内で作成したモックアップ（リポジトリ外の `website design/landingpage.png`）から
該当部分を切り出し、幅 560px の JPEG に変換したものである。

出る場所は2つある。

| 画面 | コンポーネント | 写真のとなりに何があるか |
|---|---|---|
| トップ `/` | `web/components/Personas.tsx` | 表示名のみ |
| 結果 `/report` | `web/components/RunDots.tsx` | そのプロファイルの実行結果（点1つ = 1回） |

## この写真が主張していないこと

**写っている人物を再現した、とは言っていない。**

トップでは写真の上に「AIエージェントにペルソナを演じさせない。情報のアクセスを実際に
制約してテストする。」が置かれている。**演じさせていないことを、写真と同じ画面で言う。**
結果画面では写真のとなりに実行結果そのものが並び、制約スペックは `/report/detail` にある。

写真の役割は「誰のための計測か」を示すことであって、計測結果の主張ではない。
主張の範囲は `profiles/README.md`「主張の範囲」にある。

## 未確定 — ライセンス

⚠️ **元画像の出所とライセンスは未確認である。** モックアップから切り出したもので、
元が撮影素材なのか生成物なのかをこちらで確認できていない。

- 提出前にデザイン担当が出所を確定し、この節に**出所とライセンスを明記する**。
- 確定できない場合は差し替える。写真は説明のための要素であって、
  これが無くても計測結果は変わらない。

## 注記 — `busy-worker.jpg`

この写真はモックアップで「高校生」として用意されたものである。一方このプロファイルが
測っているのは「8クリック / 2分で打ち切り」、つまり**待てる時間の短さ**なので、
カードの表示名を職業ではなく状態（「時間がない人」）にしてある。
写真を会社員のものに差し替えるなら、表示名も併せて変える
（`web/lib/profiles.ts` の `PERSONA`）。
