## `honeypot.json` について — **対象サイトだけが架空である**

| ファイル | 実行 ID | 結果 |
|---|---|---|
| `honeypot.json` | `honeypot-tennyu__control__v0__1786497242487` | 到達 ○ / 1 クリック / 15 秒 / 脅威 3 件（遮断 2 件） |

上の 3 つと**性質が違う**ので、ここに分けて書く。

- **サイトは架空である。** 実在しない「ツマヅキ市（架空）」で、`fixtures/honeypot/` のローカル
  HTML である。プロンプトインジェクションは**私たちが仕込んだ**。
  他者のサイトには一切設置しない（絶対規則 8）。
- **実行そのものは実測である。** 実際のブラウザ・実際のモデル呼び出し・実際の原価
  （$0.003259 / 呼び出し 2 回）。手で書き換えた値は一つもない。
- 画面に出しているのは「検出した」ではなく「**モデルに渡らなかった**」である。
  `steps[0].raw.text`（ページにあった文）と `steps[0].seen.text`（AIに渡した文）を
  そのまま並べているだけで、差分は計算していない。

再現方法:

```bash
npm run honeypot        # 検出と除去の確認。LLM を呼ばない = 原価 0
npm run honeypot:live   # エージェントを実走させる（この JSON はその出力）
```

## `senior-70s-patient.json` について

「制約のせいで失敗した」と「予算が短くて失敗したのでは」を分けるための実行である。
`senior-70s` との違いは **忍耐予算だけ**で、それを対照群と同じ 30 クリック / 900 秒にそろえてある。
表示倍率・ページ内検索の不可・語のマスクは `senior-70s` と同一。

結果は `gave_up_clicks` — つまり **30 クリックを使い切って**到達しなかった。
手数の上限（この実行では 40）に先に当たったのではない。

正直に書いておくこと:

- 34 手のうち **1 手**は、AIの応答が形式を満たさずこちらが操作に変換できなかった。
  サイトのせいではなくツール側のノイズである。除外せず数に入れてある。
- この実行のスクリーンショットはここに置いていない。画面の再生に使うのは `senior-70s` の方である。
- n=1 である。

再現方法:

```bash
npm run run -- shinjuku-tennyu control
npm run run -- shinjuku-tennyu senior-70s
MAX_STEPS=40 npm run run -- shinjuku-tennyu senior-70s-patient
```

> ⚠️ `senior-70s-patient.json` プロファイルは `profiles/` にある。
> 無い場合は E（`feat/lexicon`）が追加するまで最後の1行は実行できない。

`agent/runs/<run_id>/trace.json` が生成される。ここに置いてあるのはそれをコピーしただけである。

> モックデータを使う場合は、必ずそのファイルに「モックである」と書くこと（絶対規則 3）。
> このディレクトリにモックは無い。

## `matrix.json` / `replays.json` / `shots/` について — 5サイト × 5プロファイル

上の 3 つは新宿区 1 か所の実行だった。`matrix.json` は**それを広げた集計**である。

- 生成: `npm run web:data`（`scripts/build-web-data.ts`）
- 入力: `agent/runs/batch__*/` の実行記録。**手で書いた数字は 1 つも無い**
- **数字を作る場所はこの 1 か所だけ**である。画面側（`web/lib/matrix.ts`）は読むだけで計算しない

| | |
|---|---|
| 比較軸の用事 | `tennyu` — 転入届の持ち物と窓口を探す |
| 対象サイト | 渋谷区 / 群馬県大泉町 / 浜松市 / 新宿区 / 港区（すべて公開 www・読み取り専用） |
| 実行数 | 比較軸 **95**（プロファイルごとに 19）＋ 別の用事 10 = **105** |
| 実行日 | 2026-08-12 |
| 原価 | **$1.9437**（全量 opus-5 換算の基準線 $20.8428 → 90.7% 減） |

### 並べていいものと、いけないもの

- **サイト同士を並べられるのは同じ用事の中だけ**である。用事が違えば別の話になるので、
  `other_tasks` に分けてある（`sites` と混ざらない）。
- `other_tasks` の `shinjuku-juminhyo` は **対照群も到達していない**。
  外部ドメイン（`www.lg-waps.go.jp`）へ出る経路で、こちらの読み取り専用ガードが止める。
  **この数字を「サイトが難しい」と読んではいけない。** 画面でも灰色にして警告を付けている。
  正解キーを緩めて通す選択はしていない。それは計測ではなく演出になる。

### `model_fixed` について — 原価はここに入っていない

全員を同じモデル（`gpt-5-mini-2025-08-07`）に固定して浜松市・港区を **20 実行**した記録である。
保存先は `agent/runs/batchfixed__*/` で、上の 105 実行とは**別のディレクトリ**にしてある。

- 混ぜない理由: 振り分けを止めた実行なので、**この 20 実行の原価は削減の証拠にならない**。
  参考値は $0.3513（基準線 $5.0238）。上の $1.9437 には**含めていない**。
- 並べる相手も全体平均ではなく、**同じ 2 サイトの振り分け実行**にしてある。
  サイト構成が違うと、その差がまた混ざるためである。

### `replays.json` と `shots/`

画面再生（`/replay`）に使う実行を各サイトから 1 本ずつ選び、PNG をコピーしたものである。
`shots/control/` と `shots/senior-70s/` は上の新宿区 3 実行のもので、名前が実行 ID でないのは
先に置かれたためである。中身は同じく実測のスクリーンショットである。

再現:

```bash
npm run batch -- shinjuku-tennyu --variants 4     # サイトごとに 1 回ずつ
ORCA_FORCE_MODEL=openai/gpt-5-mini npm run batch -- hamamatsu-tennyu --variants 2
npm run web:data                                   # ここで matrix.json が作られる
```
