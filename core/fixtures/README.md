# core/fixtures — 契約サンプル

`core/types.ts` の `RunTrace` が 2 件入っています。
**Web 側が実行エンジンの完成を待たずに着手するため**のものです。

```bash
npm run fixture:build   # 2 件とも再生成（決定論的 — 同じ結果になります）
```

| ファイル | プロファイル | マスクの根拠 | 何を確認するためのものか |
|---|---|---|---|
| `sample-run.json` | `senior-70s` v1.0 | `comprehension_rate` — 理解率 % | 外来語の壁。200% 表示で視野が狭まる |
| `sample-run-n3.json` | `resident-n3` v1.1 | `designated_list` — 指定名簿 | **行政漢語の壁。言い換え文が付く** |

**2 件ある理由:** プロファイル 1 つは語彙ポリシー 1 つしか持ちません。
1 回の実行に 2 種類の根拠を混ぜると「このマスクは何を根拠にしたのか」に答えられなくなります。
Web 側は両方を表示するので、実行も 2 つに分けてあります。

受賞したらコードを提出します。だから、どこが実測でどこが手で作った値なのかをここに書いておきます。

検証が済んだら実際のトレースに差し替え、この表を消します。

### Web 側がこのファイルで確認すること

1. `steps[n].raw` ↔ `steps[n].seen` の切り替え。
   ステップ 1 の要素 7 番が `ウェブアクセシビリティ方針` → `ウェブ◯◯◯◯◯◯◯◯方針` に変わります。
2. `seen.elements` にはビューポート外の要素が**含まれません**（17 → 9）。
   200% 表示が視野を狭めた結果そのものです。
3. `screenshot_key` がすべて `null` です。
   **スクリーンショットなしでもリプレイが成立しなければなりません。**
   実行中にキャプチャが失敗することは実際に起きます。要素一覧とテキストだけで画面を再現してください。
4. `constraint.masked[]` の `evidence_ja` をそのまま画面に表示します。
   根拠のないマスク表示はバグです。
5. `cost.total_usd` は全ステップの `llm_calls[].cost_usd` の合計です。
   桁が合わない場合は UI 側の丸め処理を疑ってください。
6. `cost.baseline_usd` は**計算値**です。画面に「実測」と書かないでください。
7. `verdict.disagreed` が `true` のときの UI も必要です（このサンプルは `false`）。

## sample-run-n3.json

`resident-n3` v1.1（行政漢語 ＋ スマートフォン 375x667）の実行 1 件です。

### ⚠️ ここもモックです。ただし**モックの範囲が違います**

| | |
|---|---|
| **実測** | ページ 3 画面（URL・タイトル・本文・操作要素・スクロール位置）。`n3-pages.json` にそのまま入っています（2026-08-11 取得・読み取り専用） |
| **実測** | **マスク結果。`build-sample-n3.ts` が `lexicon/src/mask.ts` を実際に呼んで作ります。**手書きのマスク記録は 1 件もありません。語彙データを直せばこのファイルも変わります |
| **モック** | ステップの進行・LLM の発話・トークン数・レイテンシ |
| **計算** | 原価 — `cost_source` はすべて `"table"` です |

### Web 側がこのファイルで追加確認すること

1. **`masked[].basis` で表示を出し分けます。**
   - `comprehension_rate` → 「60歳以上の理解率 8.2%」のように **% を出します**
   - `designated_list` → 「収録語 No.97」と出し、**% は出しません**
   数値を持たない根拠に % を付けると、存在しない調査を存在すると言うことになります（絶対規則 4）。
2. **`masked[].listing.meaning` が「代わりにこう書く」の文です。**
   これは我々の意見ではなく、出入国在留管理庁・文化庁が示した言い換え文をそのまま出しています。
   レポートの改善提案はここから作ります（`findings[0].fix_ja` が実例です）。
3. `cohort` が `null` になります。「誰の理解率か」という問い自体が成立しないためです。
   `null` で落ちない UI にしてください。
4. ステップ 2 で**同じ画面の 3 本のリンクが同時に `◯◯◯` になります。**
   左右分割デモで一番効くのがこの画面です。`raw` と `seen` を並べてください。
5. 1 手目の `action.kind` が `"scroll"` です。クリック候補が画面内に 1 つも無かったためで、
   **クリック以外の行動も描画できる必要があります。**
