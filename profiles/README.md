# 制約プロファイル (Constraint Profiles)

> **이 폴더가 이 제품의 주장 그 자체다.**
> 우리는 「AI가 72세를 재현했다」고 주장하지 않는다. 그건 검증 불가능하고, 물으면 무너진다.
> 우리가 주장하는 것은 **「여기 명시된 제약 하에서 이 태스크가 실패했다」** 뿐이다.
> 그래서 제약은 프롬프트 안에 숨지 않고, **버전이 붙은 공개 명세**로 여기 나와 있다.

## 왜 프롬프트가 아니라 파일인가

「나는 카타카나 외래어를 모른다」를 프롬프트에 쓰면 LLM은 **모르는 척 연기**한다.
연기는 새어나간다 — "이게 무슨 뜻인지 모르겠다"고 말한 직후에 정확한 페이지로 이동해버린다.
지식베이스는 능력을 *추가*하지 *제거*하지 못한다.

그래서 제약은 **도구 계층에서 관측을 실제로 훼손**한다.
`lexicon.mask_below: 30` 은 연기 지시가 아니라, LLM에게 텍스트가 넘어가기 **전에** 실행되는 치환이다.
에이전트는 모르는 척하는 게 아니라 **정말로 모른다.**

## 주장의 범위

| 하지 않는 주장 | 하는 주장 |
|---|---|
| 「72歳のユーザーを再現した」 | 「60歳以上の理解率30%未満の語を隠した状態で失敗した」 |
| 「実際の高齢者はこう行動する」 | 「この制約下でのクリック経路はこうだった」 |
| 「この数字が母集団を代表する」 | 「このプロファイル v1.0 の再現結果である」 |

각 프로필의 `claims` / `does_not_claim` 필드는 **결과물에서 분리되지 않는다.**
리포트에는 항상 프로필 id + version이 함께 나간다. 분리되는 순간 검증 불가능한 주장이 된다.

## 어휘 제약의 근거

`lexicon.*` 은 전부 **国立国語研究所「外来語定着度調査」** (CC BY 4.0) 에서 온다.
- 조사어 405어 / 全国16歳以上 / 층화2단 무작위추출 / 개별면접 / n=750〜2118
- 「理解率」= 「意味が分かる」라고 답한 비율 (「何となく分かる」는 제외)
- 조사시기 **2002-11 〜 2004-08**

### ⚠️ 이 데이터의 한계 — 질의에서 반드시 나온다. 먼저 말할 것

1. **20년 전 데이터다.** 「ダウンロード」의 이해율은 2026년에는 더 높을 것이다.
2. **코호트가 다르다.** 조사의 「60歳以上」은 1944년 이전 출생자다. 2026년의 72세는 1954년생으로,
   조사 시점에는 50대였다. 즉 이 프로필은 **2026년의 고령자가 아니라 2004년의 고령자**를 모델링한다.
3. → 따라서 **절대값이 아니라 난이도 순위**로 쓴다. 그리고 결과는 **과소·과대 양쪽 다 가능**하다.
4. → 조사 미수록어는 **가리지 않는다** (`unknown: "keep"`). 근거 없는 마스킹은 하지 않는다.
   이 방향의 오차는 항상 **과소 마스킹**이다.

이 한계를 감추면 質疑에서 무너진다. 슬라이드에 각주로 넣는다.

## 프로필 일람

| id | 무엇을 재는가 | 핵심 제약 |
|---|---|---|
| `control` | **대조군.** 제약 없음 | 없음 — 「사이트가 아니라 제약 때문에 실패했다」의 증명 |
| `senior-70s` | 외래어 장벽 | 어휘 마스킹(60+, 30%) + 줌 200% + 검색 금지 |
| `resident-n3` | 다국어 패리티 | 스마트폰 + 일본어 입력 제약 + 짧은 인내 |
| `smartphone-novice` | 시각 탐색만 | **DOM 텍스트 차단, 스크린샷만** |
| `busy-worker` | 시간 압박 | 제약 없음 + 인내 예산 8클릭/2분 |

> **control이 왜 있는가:** 좌우 분할 데모에서 왼쪽이 control이다.
> 대조군 없이 「9클릭 헤매다 포기」만 보여주면 「그냥 사이트가 어려운 것 아닌가」로 끝난다.
> control이 2클릭에 도달하는 걸 나란히 보여야 **제약이 원인**이라는 주장이 선다.

## 「10명」의 분산 (R9)

같은 스펙 + 같은 사이트 + 같은 LLM이면 거의 같은 경로를 간다.
그러면 「10명」이 아니라 「1명 × 10회」가 되고 이탈률이라는 지표가 성립하지 않는다.
→ **10명 = 5개 프로필 × 2 변형.** 변형은 `variants` 필드의 진입점·인내예산 랜덤화로 만든다.
분산은 우연이 아니라 **설계**여야 하고, 그걸 설명할 수 있어야 한다.

## 버전 규칙

프로필을 고치면 `version`을 올린다. 과거 결과는 과거 버전으로 재현 가능해야 한다.
**리포트에 찍힌 버전과 지금 파일이 다르면 그 리포트는 재현 불가능이다.**
