# ツマヅキ / Tsumazuki

**どこでツマヅくか、10人が先に試す。**

URL を入れると、それぞれ違う制約を持った AI 利用者が実際にそのサイトを操作し、
**どこで手が止まったか**を記録して返します。AI HACK 2026 応募作品です。

> 「AA 準拠」のサイトを、72 歳は突破できなかった。

---

## これは何か

ユーザーテストは「正しく作れているか」ではなく「**使えなかった人がどこで諦めたか**」を知るためのものです。
けれど実際にやろうとすると、対象者を集めて日程を組んで謝礼を払って、1 回に数週間かかります。
だから多くのサイトは、リリース後に問い合わせが来るまで気づきません。

ツマヅキは、その 1 回目を数分で回します。

```
URL → 制約プロファイル 5 種 × 実行 → 各エージェントが止まった地点 → 修正案つきレポート
```

## 他の「AI にサイトを操作させる」ものとの違い

Browser Use をはじめとする既存のエージェントは、サイトを **使いこなす** ために作られています。
リンクが分かりにくくても、文字が小さくても、DOM を読んで正解にたどり着いてしまう。
だから「使いにくさ」の測定には使えません。

ツマヅキは逆です。**サイトを使いこなせない**エージェントを作っています。

そして重要なのは、それを**プロンプトでやらない**ことです。

「あなたは 72 歳です。カタカナが苦手なふりをしてください」と指示しても、
モデルは「アクセシビリティ」の意味を知ったまま、知らないふりを**演じる**だけです。
演技は漏れます。知識ベースは能力を**足す**ことはできても、**引く**ことはできません。

そこでツマヅキは、制約を**観測層で**適用します。

```
ブラウザ  →  observe()  →  constrain()  →  LLM
                            ↑
                    ここで語彙を伏せる・視界を狭める・道具を取り上げる
                    LLM は「隠された後」の画面しか見たことがない
```

`constrain()` を通らないバイトは LLM に届きません。演技する余地が構造的に存在しません。

### 実例（新宿区トップページ・文字サイズ 200%・高齢者制約プロファイル v1.0）

| | 制約前 | 制約後（エージェントが見たもの） |
|---|---|---|
| リンク | ウェブアクセシビリティ方針 | ウェブ◯◯◯◯◯◯◯◯方針 |
| リンク | サイトマップ | ◯◯◯マップ |
| 画面内の要素数 | 270 | 9 |

「アクセシビリティ」の 60 歳以上の理解率は **2.1%** です（国立国語研究所「外来語定着度調査」）。
私たちが決めた数字ではありません。伏せた語には必ず**出典と数値**が付きます。

## 主張すること / しないこと

| しない主張 | する主張 |
|---|---|
| 72 歳のユーザーを再現した | 60 歳以上の理解率 30% 未満の語を伏せた状態でタスクが失敗した |
| 実際の高齢者はこう行動する | このプロファイル v1.0 の実行結果である |
| この数字が母集団を代表する | n=125（有効ラン数）の制約プロファイル実行結果である |

レポートには**必ずプロファイル ID とバージョン**が付きます。
語彙データの限界（2002–2004 年調査・コホート不一致）は、聞かれる前に明記します。

## 制約プロファイル

制約は人格ではなく、**バージョン管理された仕様**です。`profiles/` にあります。

| ID | 制約 |
|---|---|
| `control` | 対照群。制約なし |
| `senior-70s` | 外来語マスク（60 歳以上の理解率 30% 未満）／表示 200%／ページ内検索なし |
| `smartphone-novice` | 狭い画面／スクロール量制限 |
| `resident-n3` | 日本語非母語話者を想定した語彙制約 |
| `busy-worker` | 忍耐予算が小さい（クリック数・秒数） |

## OrcaRouter

LLM 呼び出しはすべて [OrcaRouter](https://www.orcarouter.ai/) 経由です。装飾ではなく**成立条件**です。

1 回の実行は「画面を読む → 次の手を決める」をステップごとに繰り返し、
1 サイトに 5 プロファイル × 複数バリアントを流すと LLM 呼び出しは数百回になります。
全部をフロンティアモデルで回すと、1 レポートの原価がサブスク価格を超えます。

そこでルーティングの入力を **ステップ種別ひとつ**に絞りました。

| ステップ種別 | 何をするか | 必要な賢さ |
|---|---|---|
| `perceive` | 今どんな画面かを要約する | 定型処理 |
| `decide` | 次にどれを押すか | 選択肢が有限 |
| `judge` | ゴールに着いたか | 誤判定のコストが高い |
| `diagnose` | なぜ失敗したか・何を直すか | レポート本文 |

エージェント側はモデル名を知りません。ルーター側はミッションを知りません。
この分離があるので、**どのコストがどのステップで発生したか**を後から説明できます。

原価は 1 呼び出しごとに記録します（`core/types.ts` の `CostRecord`）。
API が原価を返した場合は `cost_source: "api"`、こちらが価格表で計算した場合は `"table"` と区別します。
**推定値を実測と呼びません。**

## セキュリティ

このプロダクトは、**信頼できない外部サイトのテキストを LLM に読ませて、その結果で操作させます**。
プロンプトインジェクションは想定上の脅威ではなく、業務上の前提条件です。

観測パイプラインを自前で持っているため、LLM に渡る前に検査できます。
検出結果は握りつぶさず `ThreatRecord` として記録し、画面に表示します。

## 動かす

Node 25 は `.ts` をそのまま実行します。ビルド不要です。

```bash
cp .env.example .env        # OrcaRouter の API キーを入れる
npm install                 # playwright のみ

npm run lexicon:build       # 語彙コーパス生成（398 語）
npm run lexicon:test        # マスキングエンジンのテスト
npm run probe -- <url> senior-70s   # 1 ページの制約前後を確認
npm run orca:smoke          # OrcaRouter 疎通確認
```

ブラウザはシステムにインストール済みの Chrome を使います（`channel: "chrome"`）。

## 対象サイトへの姿勢

- **読み取りのみ。** 会員登録・マイナンバー認証・フォーム送信・ログイン・電子申請システムへは入りません。
- 同一ドメインへの同時実行は 1、リクエスト間隔は 4 秒以上、robots.txt に従います。
- インジェクション検証用のハニーポットは**ローカルのフィクスチャにのみ**設置します。他者のサイトには一切置きません。

## データ出典

伏せた語には必ず出典が付きます。原本は加工せず `lexicon/vendor/` に同梱しています
（入手日・原本 URL・採用しなかった候補とその理由は [lexicon/vendor/SOURCES.md](lexicon/vendor/SOURCES.md)）。

| 使っているもの | 出典 | ライセンス |
|---|---|---|
| 外来語の理解率（`senior-70s`・398 語） | [国立国語研究所「外来語」言い換え提案／外来語定着度調査](https://mmsrv.ninjal.ac.jp/gairaigo_yoron/)（調査 2002–2004） | CC BY 4.0 |
| 行政用語の書き換え指定（`resident-n3`・134 語） | 出典：文化庁ウェブサイト（https://www.bunka.go.jp/） ／ [出入国在留管理庁・文化庁「やさしい日本語」書き換え例](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kyoiku/92484001.html)（2020-08） | 文部科学省ウェブサイト利用規約（政府標準利用規約 2.0・CC BY 4.0 互換） |
| 常用漢字の判定 | [文化庁「常用漢字表」](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/kanji/)（平成22年 内閣告示 第2号） | 著作権法 第13条第2号（告示は著作権の目的とならない） |

「やさしい日本語」書き換え例は**理解率の調査ではなく、行政が書き換えを指定した用語の一覧**です。
だから画面に % を付けません。この違いは `lexicon/data/yasashii.manifest.json` にも書いてあります。
